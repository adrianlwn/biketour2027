# Gravel Toscane 2027

Road book web de la boucle gravel De Siena à Chiusi (30 mai – 5 juin 2027) : carte interactive, scénarios pour le premier jour, profils d'altitude, pentes, trafic, photos des lieux et GPX par étape. Fonctionne hors ligne une fois ouvert.

Application statique : ouvrir `index.html` via un serveur (`python3 -m http.server`).

- Tracés : [BRouter](https://brouter.de) (profils gravel, safety, trekking), données © contributeurs OpenStreetMap
- Photos : Wikimedia Commons, auteurs et licences indiqués dans l'application
- Fonds de carte : Esri, CyclOSM, OpenTopoMap
